### 1-1. 앱 구도 (5개 표면)

| 표면 | 라우트 | 사용자 | 핵심 동선 |

### 1-2. 핵심 기능 14종

1. **인증**: 카카오 OAuth(일반) + Email/Password(매장/대회사) + 일반 사용자 단일 페이지 가입 + 비번 분실 복구
2. **매장찾기**: 목록/지도 토글 + 10km 자동확장(20→30km) + 위치거부 시 전국 fallback
3. **LIVE 토너 실시간 송출**: 타이머 + 사운드 + BREAK 명확 표시 + 사용자 앱 5곳 동시 노출
4. **타이머 시스템**: 드래그 진행바 + sec=0 자동 advance + BlindStructure 10레벨 + 3 layout(데스크탑·세로·가로)
5. **PRIZE POOL 3 모드**: hidden / total / distribution (사용자 앱 금지 / 매장·TV 허용)
6. **예약**: pending → confirmed → check_in → completed + 1매장 1활성 + autoComplete 30분 cron + 사용자 발의 취소 → 매장 승인
7. **오늘의 소식**: 24h 만료 + 1일 3건(Free) + cardEmojis 최대 3개 + 9색 + 자동 슬라이드 + 매장 재등록
8. **커뮤니티**: 구인 / 구직(딜러 이력서, 매장 owner만 열람) / 핸드분석 게시판 v0.5(좋아요/대댓글/이미지 4장)
9. **체크인(소셜 v0.1)**: 24h + 1매장 1회 + 홈 "지금 다녀온 사람들" 5건
10. **광고**: 본사 수동 발급 + 4-tier(Free/Light/Pro/TourneyPack) UI 게시 + 결제 🔒 준비 중
11. **알림**: FCM + 인앱 알림 11종 + /m/notifications + 5페이지 마운트 NotificationBell
12. **시리즈/위성**: organizer 5메뉴 (일부 hide 상태)
13. **모더레이션**: 토큰 매칭 + Firestore 동적 사전 + 법적 차단 ~20개 코드 fallback
14. **유튜브 콘텐츠 자동 큐레이션**: cron + 3-슬롯 모델 + 5채널 시드

### 1-3. 디자인 시스템 (Pink Rabbit v3.0)

- **브랜드**: `#FF1F8F` 핫핑크 + `#F59E0B` 골드 + `#E53E3E` LIVE 빨강
- **DS 토큰**: Tailwind v4 + CSS 변수 + `.pr-card` / `.pr-pill` / `.pr-chat-*` / `.lift` / `.tap` / `.skel` 일관 유틸
- **다크/라이트 정책**: 매장 어드민=라이트 단일 / 본사 어드민=다크 단일 / 사용자 앱=라이트 (토글 노출 X)
- **모바일 우선**: `max-w-md` + 5탭(홈/매장찾기/토너/즐겨찾기/내정보) + 하단 고정 탭바
- **TV 폰트**: 8종 슬라이더 실시간 (titleScale/levelScale/anteScale 등) + clamp 1.5~2배 확대
- **로고**: `RabbitLogo` (badge/mark variant) + 5진입점 일괄 적용

### 1-4. 누적 의사결정 105건 메모리에서 도출된 핵심 정책

- 사용자 앱에 **상금 금액 노출 금지** (매장/TV만 허용)
- 카카오맵 SDK 일일 30만 호출 보호 → 신규 호출 자제 + 거리만 haversine
- 사행성 키워드 자동 차단 (환금/베팅/도박/캐시게임)
- LIVE 타이머 안정화 마라톤 5월 28일 14 commits 거쳐 sec=0 트리거 / advance grace 3s / 사운드 cooldown 3s 등 정교한 race condition fix 완료
- 출시 전 데이터 초기화 스크립트 준비됨 (thethego@naver.com + isDemo=true 매장 100개 보존)

## Phase 3 — 그룹별 대표 인터뷰 (32명 발췌)

### 인터뷰 A1. 김상우 (38·신규 부산서면 펍 사장)

## 최종 결론

### "내가 외부 사용자 100명이라면 출시 전 반드시 고쳐야 할 것 8개" (P0)

1. **매장 가입 승인 SLA 명시** — 80% 매장이 불안 호소
2. **"홀덤펍/토너 정보 플랫폼" 명확화 카피** — 도박 앱 오해 100% 차단
3. **비로그인 둘러보기 동선** — 가입 강제 인상 차단
4. **organizer 5메뉴 정리** — 대회사 그룹 100% 혼란
5. **매장 가입 마법사 4→3 step 압축** — 이탈률 -30% 예상
6. **5탭 라벨 직관성 점검** — 초보 5초 인지
7. **"곧 출시" placeholder 일관 디자인** — 신뢰도 보호
8. **첫 진입 시 LIVE 톤 다운** — 여성/일반인 진입장벽 ↓

**예상 작업 시간**: 약 14시간 (솔로 빌더 풀타임 2일)
**예상 효과**: 가입 전환율 +20~30%, 이탈률 -25%, 외부 비-홀덤인 진입장벽 ↓

### 출시 후 1주 내 P1 12건 (약 1.5~2주 작업)

가장 임팩트 큰 것: **카카오 알림톡 연동** (P1-1, 3일) → 매장 사장과 사용자 모두의 알림 미수신 문제 근본 해결

### 외부 시각 객관 평가

**강점**:
- LIVE 타이머의 완성도와 안정화 수준 (5월 28일 마라톤 14 commits)는 경쟁사 압도
- Pink Rabbit 디자인 시스템의 일관성 (v1 → v3.0 깊이 마이그레이션)
- 데이터 모델의 SNS 확장 호환성 (`authorType` 분리)
- 메모리 기반 의사결정 추적 (105 메모리 파일)

**약점 (외부 사용자 시각)**:
- 사용자 앱 첫 진입 5초 인지 동선이 "콘텐츠 허브"라 정체 인지 부족
- 50대 베테랑 사장 / 여성 / 외국인 / 비-홀덤인 페르소나 미커버
- 카카오 알림톡 같은 "카톡 사용자 기대값" 미반영
- 결제 시스템 부재 상태에서 4-tier 가격표 게시 → 신뢰도 의문

**한 줄 종합**:
> "기능적으로는 출시 가능하나, 외부 사용자가 5초 안에 '이 앱이 뭔지' 알아볼 수 있는 첫 진입 동선 8건만 다듬으면 출시 품질 90% → 99%로 도약."
